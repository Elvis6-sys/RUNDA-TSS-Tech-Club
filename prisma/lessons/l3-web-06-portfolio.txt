BUILD A STATIC PORTFOLIO SITE
==============================

This is your capstone for the Web Development track.
You will build and deploy a real portfolio site that anyone can visit.

WHAT TO BUILD
-------------
A personal portfolio with 4 sections:
  1. Hero      — your name, title, and a short tagline
  2. About     — 2-3 sentences about you and your goals
  3. Projects  — 2-3 things you have built (even small ones)
  4. Contact   — your email or GitHub link

FOLDER STRUCTURE
----------------
  my-portfolio/
    index.html
    style.css
    script.js       (optional — for small interactions)
    images/
      profile.jpg

STEP 3 — DEPLOY TO GITHUB PAGES
---------------------------------
  1. Push your project to a GitHub repository
  2. Go to Settings → Pages
  3. Under "Source" select: Deploy from a branch → main → / (root)
  4. Click Save
  5. Wait ~60 seconds
  6. Your site is live at: https://yourusername.github.io/my-portfolio

CHECKLIST BEFORE SUBMITTING
-----------------------------
  ✓ Site loads on mobile (test in DevTools at 375px)
  ✓ All 4 sections present (Hero, About, Projects, Contact)
  ✓ Nav links scroll to the correct section
  ✓ No broken images or links
  ✓ Deployed and accessible via GitHub Pages URL
  ✓ GitHub repo has at least 3 commits with clear messages

PRACTICE
--------
Build and deploy your portfolio.
