CSS LAYOUTS & FLEXBOX
=====================

CSS (Cascading Style Sheets) controls how HTML looks.
HTML = structure. CSS = appearance.

HOW TO LINK CSS
---------------
Inside your <head>:
  <link rel="stylesheet" href="style.css" />

Or write styles directly in HTML (not recommended for large projects):
  <style>
    h1 { color: blue; }
  </style>

CSS SYNTAX
----------
  selector {
    property: value;
    property: value;
  }

  h1 {
    color: #1a73e8;
    font-size: 32px;
    font-weight: bold;
  }

SELECTORS
---------
  h1          — targets all <h1> tags
  .card       — targets elements with class="card"
  #logo       — targets the element with id="logo"
  p.intro     — targets <p class="intro"> only
  nav a       — targets <a> tags inside <nav>

THE BOX MODEL
-------------
Every element is a box with 4 layers:

  ┌─────────────────────────────┐
  │           margin            │  ← space outside the border
  │  ┌───────────────────────┐  │
  │  │        border         │  │  ← the visible border line
  │  │  ┌─────────────────┐  │  │
  │  │  │     padding     │  │  │  ← space inside the border
  │  │  │  ┌───────────┐  │  │  │
  │  │  │  │  content  │  │  │  │  ← your text/image
  │  │  │  └───────────┘  │  │  │
  │  │  └─────────────────┘  │  │
  │  └───────────────────────┘  │
  └─────────────────────────────┘

  .card {
    padding: 16px;       /* space inside */
    margin: 8px;         /* space outside */
    border: 1px solid #ccc;
    border-radius: 8px;  /* rounded corners */
  }

FLEXBOX
-------
Flexbox makes it easy to lay out items in a row or column.

  .container {
    display: flex;
    flex-direction: row;      /* row (default) or column */
    justify-content: center;  /* horizontal alignment */
    align-items: center;      /* vertical alignment */
    gap: 16px;                /* space between items */
  }

justify-content values:
  flex-start   — items at the start
  flex-end     — items at the end
  center       — items in the middle
  space-between — equal space between items
  space-around  — equal space around items

RESPONSIVE DESIGN WITH FLEXBOX
-------------------------------
  .cards {
    display: flex;
    flex-wrap: wrap;   /* items wrap to next line if no space */
    gap: 12px;
  }

  .card {
    flex: 1 1 200px;   /* grow, shrink, minimum width 200px */
  }

COMMON PROPERTIES
-----------------
  color           — text colour
  background      — background colour or image
  font-size       — text size (px, rem, %)
  font-weight     — bold (700) or normal (400)
  width / height  — element dimensions
  display         — block | inline | flex | grid | none
  position        — static | relative | absolute | fixed
  border-radius   — rounded corners
  box-shadow      — drop shadow
  opacity         — transparency (0 = invisible, 1 = fully visible)
  cursor: pointer — hand cursor on hover

--------

  2. Make the <nav> links display in a row using flexbox
  3. Add padding and a border-radius to a card <div>
